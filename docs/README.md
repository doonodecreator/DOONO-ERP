## Reading order

A new school operator should begin with the complete manual’s product overview, role catalogue, first school setup, admissions, portals, results, finance, and onboarding sections. A developer should read the architecture, tenancy, API conventions, data model, source map, and document maintenance sections. A deployment administrator should read the deployment architecture, environment configuration, backup and recovery, testing, security checklist, Termux procedure, and known limitations sections.

The documentation is source-grounded and must be updated whenever routes, roles, permissions, workflows, providers, database behavior, or deployment assumptions change.
