# UI consistency pass findings

The shared component library currently includes PageContainer, PageHeader, SectionCard, DashboardGrid, StatCard, FormField, Button, Modal, DataTable, LoadingSpinner, EmptyState, and Alert. DashboardGrid now imports the shared dashboard stylesheet. DataTable guards malformed API data with Array.isArray and renders a responsive table wrapper without per-column inline widths.

The generic Dashboard.jsx was migrated from legacy react-icons and inline styles to PageContainer, PageHeader, DashboardGrid, StatCard, SectionCard, LoadingSpinner, EmptyState, Alert, Button, and the shared role helper. The production build passed after this migration.

There are 19 *Dashboard.jsx files. Existing shared-component adoption is uneven: PlatformOwnerDashboard and ProprietorDashboard are substantially standardized; FormTeacherDashboard, NurseryHeadDashboard, PrimaryHeadmasterDashboard, SecondaryPrincipalDashboard, TeacherDashboard, and several academic dashboards use PageHeader/LoadingSpinner/EmptyState but still contain legacy metric/card markup; AccountantDashboard is a large legacy portal with inline tables and a custom modal; remaining role dashboards require targeted review. Legacy dashboard.css still contains old class aliases and needs token-based normalization so unconverted dashboards visually align during migration.
The repository did not contain FormActions.jsx, so a shared FormActions primitive was added under components/forms. The shared styles use variables.css tokens, while components.css still contains legacy hard-coded aliases; new rules should be added without breaking existing classes.
